# Etch-a-sketch

A browser-based Etch-a-Sketch application built with HTML, CSS and Javascript.

It allows users to draw on a customizable grid using different color modes, including RGB and Rainbow.

## Preview

![etch-a-sketch](./images/Etch-a-sketch.png)

## Features 
-Adjustable grid size
-RGB color mode
-Eraser tool
-Rainbow color mode
-Mouse drawing
-Clear grid button
-Responsive layout

## Technologies Used
-HTML5
-CSS3
-Vanilla JavaScript(ES6)
-Git
-Github

## What i Learned

This project helped me become more comfortable working with JavaScript and the DOM

-One of the biggest challenges was learning how to structure my code by defining constants and default values before implementing the main functionality. This was a new concept for me , and guidance from a senior developer helped me better understand how to organize my code
-Implementing the Rainbow color mode required the most problem-solving. It took time to figure out the logic and get it working as intended, but it taught me the importance of breaking complex problems into smaller steps.
-I became more confident with DOM manipulation and realized that, with enough practice, it becomes much more intuitive.
-As the projects become more complex, I have also learned that reading documentation is an essential part of the development process. I no longer expect to remember everything and instead focus on understanding concepts and knowing where to find reliable information.
